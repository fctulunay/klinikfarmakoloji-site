# klinikfarmakoloji.com — static site

Static replica of **Klinik Farmakoloji Dosyası** (klinikfarmakoloji.com), converted from the
original Drupal 8 site in September 2026.

- Every page is a plain HTML file (`<path>/index.html`); files live under `sites/default/files/`.
- Old `/index.php/...` and `/node/N` addresses redirect to the new clean addresses.
- All downloadable documents are public; there are no member accounts.
- Hosted on DigitalOcean App Platform (static site) — every push to `main` republishes the site.
